## Starters

Scaffold from a template with `qinit new <name> --template <kind>`:

- `counter` — uint64 state, Inc / Get. The hello-world.
- `hashmap` — `HashMap<id, uint64>` — Set / BalanceOf / Stats.
- `asset` — issue an asset (issuer = SELF), move shares.
- `intercontract` — call another contract.

All four are real, tested contracts. Start from one and edit.
